# German Flashcards Architecture

A portfolio project to demonstrate software architecture and system design using a German flashcards application.

## Goal
Build a modular monolith application with clean separation of concerns:
- frontend
- services
- repositories
- models
- db
- api

## Current Stack
- Python
- Streamlit
- Pytest

## Planned Extensions
- Excel-based flashcard loading
- Example generation
- Docker
- Jenkins CI/CD
- REST API
- database integration
